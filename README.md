# Breathe-O-Meter

Breathe-O-Meter is a small desktop hardware project for Hack Club Fallout. It measures room temperature, humidity, and air pressure, then shows the data on a built-in screen.

Since it will usually sit plugged into a computer, I also want it to work as a tiny desk companion with a few buttons for simple macro/macropad actions (maybe some knobs aswell?).

## Features

- Temperature, humidity, and pressure sensing
- Built-in display for live room readings
- Comfort/status indicator
- Programmable buttons for simple macros
- USB-powered desktop design

## Hardware

The project will use an ESP32 or ESP32-S3, a BME280 environmental sensor, a larger (3-4 inch?) display, and several keys.
